## O que muda

- **Um texto para citação por item da ABNT NBR 17225.** No relatório que se abre pelo botão “Abrir relatório
  completo”, o quadro de constatações gerava um texto para copiar por elemento, mesmo quando todos se referiam ao
  mesmo item da norma. Agora, quando um item tem mais de uma constatação, a lista continua mostrando cada elemento
  e a sua constatação, e logo abaixo aparece **um só** “Texto para citação (abrange os N elementos acima)”, com um
  único botão de copiar.
- O texto único diz a data, a página e o item da norma uma vez, cita todos os elementos pelo nome e lista as
  evidências sem repetir as que são iguais (como a captura da página inteira). Elementos com a mesma constatação são
  citados em sequência numa frase só; constatações diferentes ficam numeradas “(1) …; (2) …”. Elementos com o mesmo
  nome aparecem com a quantidade, por exemplo “ao botão sem nome (3 elementos)”.
- Itens com uma única constatação continuam exatamente como antes.
- Os relatórios exportados (HTML, PDF, CSV e JSON) continuam com uma citação por elemento.
- A captura 4 da loja mostra o novo texto único do item 5.1.13.
